# Waterfall Preventa - Canal Tradicional

Dashboard estatico (una sola pagina, sin dependencias externas) del waterfall de Preventa:
Descarga Autoventas -> Ruteo Distribucion -> Rebaja productiva -> Quiebre Picking Cajas.

Se publica automaticamente al ejecutar actualizar_preventa.py.
Solo se publica el artefacto index.html; el codigo del pipeline no vive en este repo.
